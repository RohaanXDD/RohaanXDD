# Rohaan

Building **[Secorvia](https://www.secorvia.com)** cloud security for teams
that do not have a security team.

Most cloud scanners hand you two thousand findings sorted by severity.
Secorvia tells you which ones someone could actually use against you.

### What I have shipped

- **[frontdoor](https://github.com/secorvia/frontdoor)** open source CLI
  that maps the federated trust into your cloud accounts. Finds who can walk
  in from outside: OIDC, SAML, cross-account and cross-cloud paths.
  AWS, GCP, Azure. One binary, no database.

- **Secorvia** free tier, no card.

Working on this on my own. If you run cloud infrastructure without a
dedicated security person, I would like to hear what actually hurts.
